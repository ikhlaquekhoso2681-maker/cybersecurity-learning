# Networking Notes

## What is Computer Networking?

Computer networking is the process of connecting computers and other devices so they can communicate and share data.

## IP Address

An IP address identifies a device on a network.

Examples:
- IPv4: `192.168.1.10`
- IPv6: `2001:db8::1`

## MAC Address

A MAC address is a unique hardware address associated with a network interface.

## TCP vs UDP

### TCP
- Connection-oriented
- Reliable
- Used when accurate delivery is important

### UDP
- Connectionless
- Faster and lightweight
- Does not guarantee delivery

## Common Protocols

| Protocol | Purpose |
|---|---|
| HTTP | Web communication |
| HTTPS | Secure web communication |
| DNS | Converts domain names to IP addresses |
| DHCP | Automatically assigns IP addresses |
| SSH | Secure remote access |
| FTP | File transfer |

## Common Ports

| Port | Protocol |
|---:|---|

| 53 | DNS |
